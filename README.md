# Sistema de control de un motor y un sensor ultrasónico

Proyecto desarrollado en TinkerCAD para simular un vehículo que emite una alerta en forma de sonido al desplazarse hacia atrás cuando detecta objetos cercanos. La simulación emplea un Arduino Uno, cuatro motores DC, un puente H, un sensor ultrasónico de distancia, un buzzer y cables de conexión. El sistema utiliza las mediciones del sensor para determinar la proximidad de los objetos y generar un sonido de advertencia. Este proyecto permitió explorar la integración de sensores y actuadores para desarrollar sistemas de alerta, como el que se busca implementar próximamente en una simulación de una ambulancia.
